# Glow OS — Ver 1.1

**HealthKit / Apple Watch 連携 · Personal Life Operating System**

ユーザーが入力しなくても生活習慣を自動取得し、AIが健康状態と美容状態を分析するスマホ向けアプリのプロトタイプです。

`index.html` 単体で動作します（追加のビルド・依存なし）。ブラウザで開くか、スマホ実機サイズで表示してください。

## 実装した機能（仕様マッピング）

| # | 機能 | 画面 |
|---|------|------|
| 1 | 歩数連携（歩数 / 距離 / 消費カロリー・達成率） | ホーム → 運動・歩数 |

## 設計メモ

- モバイルファースト（iPhoneサイズの単一画面、下部タブ + 中央の水分記録FAB）。
- グラフはすべて Canvas で自前描画（外部ライブラリ非依存）。歩数の週次バー、体重推移、肌スコア予測、睡眠段階を可視化。
- 現状はデモ用のモックデータで HealthKit / Apple Watch 同期を再現。実機ではネイティブ層（Swift / HealthKit）で `HKHealthStore` から歩数・睡眠・心拍・体重等を取得し、本UIにバインドする想定です。
- AIインサイトの文言は仕様書の例（「目標達成です」「昨日より深い睡眠が増えています」等）をそのまま反映。

## コンセプト

Glow OSは Habit Appでも美容アプリでもなく、睡眠・食事・運動・美容・健康を統合し、AIが「理想の自分」になるまで伴走する **Personal Life Operating System** です。
